## 알려진 sleeper 이슈 (다음 세션이 알아야 할 것)

### 1. `runtime/scene-objects.js::_applyTransform` 의 rotation 단위 불일치
- 코드: `THREE.MathUtils.degToRad(rx)` (line 22-23 부근)
- 우리 스키마/Inspector: rotation 은 **radians** 로 저장
- 현재는 사용자가 rotation = 0 이라 영향 없음. **사용자가 회전 값 만지는 즉시 어긋남.**
- 수정: `_applyTransform` 의 degToRad 제거. 또는 schema 도 deg 로 통일하고 Inspector 도 그에 맞춤.

### 2. cargo incremental cache 가 변경을 못 잡는 패턴 (macOS)
- 증상: src 파일 수정 후 `npm run tauri dev` 가 `Finished in 0.18s` 로 끝나며 옛 바이너리 그대로 띄움
- 추정: mtime 1초 정밀도 + 빠른 dev/save 로 stale 검사 통과
- 우회: `touch <변경한 .rs 파일들>` 후 재시작. 빌드 로그에 `Compiling open-ar-editor` 라인이 떠야 진짜 재컴파일.
- **다음 세션도 Rust 변경 후 dev 결과가 의심스러우면 무조건 touch 부터.**

### 3. PreviewModal 이 `alert` 사용 — macOS WKWebView 에서 동작 미보장
- `prompt` 가 막힌 건 확인됨. `alert` 는 일단 동작하는 듯하나 미검증.
- 안전하게 모든 alert 도 inline 토스트/모달로 교체하면 좋음 (낮은 우선순위).

### 4. cloudflared 첫 다운로드 ~7MB 는 GitHub Release 최신 버전 기준 — 실제 받아보면 ~36MB
- 압축 풀린 binary 가 36MB. 다운로드 자체는 ~10MB 가량 (.tgz).
- PreviewModal 안내 문구 갱신 가능 ("~7MB" → "약 10MB 다운로드, 36MB 캐시").

### 5. `tunnel_start` 의 origin 이 `localhost:<port>` 고정
- preview_build_and_start 가 0.0.0.0 에 bind 하지만 cloudflared 는 localhost 로 connect.
- 같은 머신이라 동작하나, 향후 분리 시 주의.

3. **Phase 3**: Edge 검증 — Trigger → Action 만 허용. 노드 팔레트 (좌측 또는 드래그 추가)
4. **Phase 4**: `graph.webar.json` 직렬화 + `projectStore` 확장 (`graph` slice 추가, `saveProject` 가 graph 도 같이 저장)
