### 스키마 v0.1.0 확정 3건

1. **scale 경로 이중성**: `objects.{id}.scale` uniform + `objects.{id}.scale.{x|y|z}` 축별. position/rotation 은 축별만.
2. **audio.spectrum 인덱스**: dot-case `audio.spectrum.N` (0-indexed, pattern `^audio\.spectrum\.\d+$`).
3. **action.playSound / playVideo**: `oneOf(objectId, src)` — 정확히 하나. `objectId` = 장면 오브젝트 참조, `src` = 일회성 경로.

### 부분 성공 / 미검증

| 항목 | 상태 |
|---|---|
| Tauri 데스크톱 창 **실제 기동** | ⚠️ 바이너리가 `Running target\debug\open-ar-editor.exe` 출력 후 exit 0 으로 조용히 종료. panic 로그도 없음. 창이 깜빡 뜨는지 여부 사용자 확인 필요. 의심점은 WebView2 런타임 부재, `lib.rs` 엔트리포인트 구조, dev 환경 변수. |
| R3F 실 렌더 | 브라우저에서 미확인. Vite 번들까지는 통과했으나 `<Canvas>` 마운트, drei `TransformControls` / `Outlines` 의 prop 호환성은 런타임에서만 드러남. |
| Tauri `invoke` 왕복 | 창이 기동되지 않아 미확인. 계약은 프론트 `src/tauri/api.ts` 와 Rust 커맨드 시그니처 수준에서만 맞춤. |
| runtime-prototype 실기기 AR | 미확인. `.mind` 타깃 파일과 `.glb` 에셋, HTTPS 서빙(mkcert/ngrok/cloudflared) 필요. |
| `convertFileSrc` 비동기 처리 | 뷰포트가 현재 `file://` 폴백만. Tauri dev(`localhost:1420`)에서 로컬 에셋 텍스처 로드 실패 예정. 에이전트 E 보고. |
| `.preview-tmp` 덮어쓰기 | Rust `export_project` 가 비어있지 않은 디렉토리에 에러를 내도록 되어 있어 preview 재시작 시 사용자에게 한국어로 삭제 안내. MVP 3 이전 `preview_build_and_start` 단일 커맨드로 통합 필요. |

## 빌드 중 발견·수정된 이슈

테스트를 돌리면서 7건을 고치고 main 에 반영했다.

| 파일 | 문제 | 수정 |
|---|---|---|
| `.npmrc` | `auto-install-peers` 는 pnpm 전용. npm 이 경고. | 삭제. 사용 기준을 npm 으로 확정. |
| `package-lock.json` | git 에 없었음. | 커밋 추가. npm 에 락파일 기준 통일. |
| `tsconfig.node.json` | `composite: true` 누락. tsc 가 `References` 검사 실패. | `composite` + `emitDeclarationOnly` + `outDir` 추가. |
| `src/shared/types.ts`, `docs/schemas/types.ts` | `NodeBase.position` (2D 캔버스 좌표) 과 `NodeActionMoveTo.position` (3D) 이 같은 속성명으로 충돌. | `NodeBase.position` → `graphPosition` 으로 개명. 타입 이름도 `NodePosition` → `NodeGraphPosition`. |
| `src-tauri/Cargo.toml` | 커맨드에서 `log::info!` / `warn!` 사용하는데 `log` 크레이트가 의존성에 없음. | `log = "0.4"` 추가. |
| `src-tauri/src/commands/preview.rs` | `preview_start` 가 `std::sync::Mutex` 가드를 들고 `.await` 너머로 살아서 `!Send`. | 가드를 블록으로 스코프해 `.await` 전에 드랍. |
| `src-tauri/tauri.conf.json` | `beforeDevCommand: "pnpm dev"` 설정. pnpm 미설치. | `"npm run dev"` / `"npm run build"` 로 교체. |
| `src-tauri/tauri.conf.json` | `plugins.dialog: {}` — dialog 플러그인은 unit(`null`) 기대, 빈 맵이면 deserialize panic. | `plugins: {}` 로 변경 (dialog 는 `init()` 호출로만 활성화). |
| `src-tauri/icons/` | `icons/icon.ico` 부재 → tauri-build 가 Windows Resource 생성 실패. | PowerShell System.Drawing 로 1024² source.png 생성, `npx tauri icon` 으로 전체 세트 생성 (ico/icns/png 각 해상도). |

## 다음 착수 지점

사용자 지시 순서대로 계획하되, 의존성이 있으니 그룹화한다.

### (a) 직접 이어 붙일 만한 것 — Wave 3 마무리
- **Tauri 창 기동 불안정 해결**: `lib.rs` 의 `run()` 엔트리 구조, `main.rs` 가 `run()` 을 호출하는지 확인, WebView2 Runtime 설치 여부 확인 (`HKLM\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients` 키). 필요 시 Evergreen Bootstrapper 안내.
- **convertFileSrc 비동기 통합**: Viewport 에서 async path resolver + React state 캐시로 에셋 텍스처 로드.
- **preview 재시작 자동화**: Rust 쪽 `preview_build_and_start` 단일 커맨드로 `export + serve` 통합. `.preview-tmp` 삭제 포함.
- **export 후 project.exports[] 자동 append**: `export_project` 성공 시 project.webar.json 에 기록 추가하고 저장.

### (b) MVP 2 기능 완성도
- **GLB 애니메이션 재생**: SceneObject3D 에 `useAnimations` 연결.
- **material.opacity / emissiveIntensity** Inspector 편집 및 뷰포트 반영.
- **Asset drag-drop** 패널 → 뷰포트.
- **템플릿 1개**: 포스터 기반 AR — 사용자가 새 프로젝트를 만들면 자동으로 이미지 타깃 1개 + GLB plane 1개가 세팅되는 최소 템플릿.

### (c) 실기기 검증 경로 정비
- runtime-prototype 용 샘플 `.mind` + 저용량 GLB 하나를 `runtime-prototype/assets/` 에 동봉하고 README 에 "바로 실행 예제" 섹션 추가.
- mkcert 로컬 HTTPS 설정 스크립트 혹은 cloudflared 자동 터널 커맨드를 PreviewModal 에서 바로 띄울 수 있게 Tauri 측 헬퍼 한두 개.

### (d) MVP 3 준비 — Event Graph
- `src/editor/node-graph/` 를 placeholder 에서 React Flow 기반으로 교체.
- `graph.webar.json` 을 에디터가 읽고 쓰도록 `projectStore` 확장.
- 노드 팔레트 (입력·동작·데이터 노드 카테고리별) + Edge 검증 (타입 맞는 연결만 허용).
